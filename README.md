## 📌 Descrição

Este repositório contém a implementação de uma **classe Calculadora** em Java. O projeto demonstra o uso de **construtores** e **sobrecarga de métodos**, permitindo realizar somas com diferentes tipos e quantidades de números, exibindo os resultados diretamente no console.

O sistema exemplifica conceitos de **programação orientada a objetos** e **polimorfismo por sobrecarga**, sendo ideal para estudo e aprendizado.

---

- **IDE:** Eclipse / IntelliJ / VS Code

---

## 📋 Estrutura do Projeto

A classe foi organizada da seguinte forma:

- **Construtor sem parâmetros** que realiza soma fixa e exibe o resultado.  
- **Construtor com dois parâmetros inteiros** que soma os valores fornecidos e exibe o resultado.  
- **Métodos `somar` sobrecarregados** para:  
  - Somar dois inteiros  
  - Somar três inteiros  
  - Somar int + float  
  - Somar float + int  
- Cada operação calcula o valor e imprime no console.
